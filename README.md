# E-Commerce Sales Data Analysis Using Python

## Project Overview
This project analyzes e-commerce sales data using Python to identify sales trends, product performance, and revenue insights.

## Dataset
- 100 records
- 8 columns
- Includes customer, city, product, category, quantity, price, and order date information.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Tasks
- Data loading and exploration
- Data cleaning and preprocessing
- Revenue calculation
- Sales analysis by product and category
- Data visualization using charts

## Project Objective
To analyze sales data and extract meaningful business insights through Python.

## Files
- `project.ipynb` – Python analysis notebook
- `ecommerce_sales.csv` – Dataset
